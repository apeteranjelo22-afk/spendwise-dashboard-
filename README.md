
# SpendWise Dashboard

## Project Description

SpendWise is a personal finance dashboard developed
using HTML, CSS and JavaScript.

The application allows users to enter their monthly
budget and total expenses. It calculates the remaining
balance and displays a financial report in the browser
console.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Implemented

### 1. Variables

The application uses variables to store the monthly
budget, total expenses and remaining balance.

### 2. Data Types

Numbers are used for financial calculations, while
strings are used for currency and messages.

### 3. User Input

The prompt() function collects the monthly budget
and total expenses from users.

### 4. Calculations

The application subtracts total expenses from the
monthly budget to determine the remaining balance.

### 5. Functions

The calculateBalance() function performs budget
calculations and returns the remaining balance.

The getAmount() function collects and validates
financial information.

### 6. Displaying Results

The console.log() function displays the monthly
budget, expenses, remaining balance and budget status.

## Project Files

- index.html: Provides the dashboard structure.
- style.css: Controls the dashboard appearance and layout.
- script.js: Handles user input and financial calculations.
- README.md: Documents the project.

## How to Run the Project

1. Open index.html in a web browser.
2. Enter your monthly budget when prompted.
3. Enter your total expenses.
4. Open the browser Developer Tools.
5. Select the Console tab.
6. View your financial report.
